### 🫁 PulmoScan AI — Chest X-Ray Analysis System

[![Live Demo](https://img.shields.io/badge/🌐%20Live%20Demo-Visit%20Now-00f0ff?style=for-the-badge)](https://pulmoscan-frontend.vercel.app)
[![Accuracy](https://img.shields.io/badge/🎯%20Accuracy-96.22%25-22d3ee?style=for-the-badge)](#)
[![PyTorch](https://img.shields.io/badge/PyTorch-EE4C2C?style=for-the-badge&logo=pytorch&logoColor=white)](#)
[![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge&logo=nextdotjs&logoColor=white)](#)

</div>

> An AI-powered web application that analyzes chest X-rays and detects **COVID-19, Lung Opacity, Normal, and Viral Pneumonia** with **96.22% accuracy**.

**Key Features:**
- 🧠 Deep Learning model (PyTorch CNN) — 96.22% test accuracy
- 🎯 Grad-CAM heatmap visualization — shows which lung regions AI focused on
- 💬 Multilingual AI Medical Chatbot (Urdu + English)
- 📄 PDF report export + Scan history
- ⚡ FastAPI backend deployed on Railway · Next.js frontend on Vercel

| Class | Accuracy |
|-------|----------|
| COVID-19 | 98.3% |
| Lung Opacity | 94.7% |
| Normal | 96.2% |
| Viral Pneumonia | 97.5% |
